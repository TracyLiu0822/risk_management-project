# 项目进度

最后更新：2026-06-07

## 当前里程碑

P0 与 P1 已完成，项目具备可运行的 Tutor MVP 业务闭环。

## 已完成

- JWT 注册、登录、刷新和当前用户接口。
- 学生、教师角色鉴权。
- 私有教师注册码。
- 本地课程资料检索。
- 可选 OpenAI 回答和无 Key 降级回答。
- 学生问答记录持久化。
- 学生历史和教师审阅接口。
- 最小前端业务页面。
- FastAPI 托管 Next.js 静态导出，实现单网址访问。
- Alembic 初始迁移。
- 8 个后端测试，覆盖率 71%，包含网页静态托管与 API 路由优先级。

## 当前限制

- 本地检索是词法相关度，不是向量语义检索。
- Token 保存在浏览器 Local Storage，适用于当前课程 MVP，不是最终生产安全方案。
- 教师可以查看所有学生记录，尚未按班级隔离。
- RAG 搜索接口尚未限流。
- 启动时仍会调用 `create_all` 作为开发兜底，正式环境应只使用 Alembic。
- 前端尚未在本次环境执行 npm 构建验证。

## 下一阶段（P2）

建议按照以下顺序开发：

1. 建立 Course、Chapter、Class、Enrollment 和 Progress 模型。
2. 将教师问答查看权限限制到本人班级。
3. 为课程资料增加课程 ID、章节 ID 和上传者元数据。
4. 增加前端资料上传和课程筛选。
5. 引入真正的向量检索并建立离线评测集。
6. 在 Tutor 稳定后开发 Quiz Agent。
7. 最后开发 Grading 和 Teaching Analytics。
